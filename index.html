Важно: это настоящий виджет iPhone через Scriptable

Сам сайт нельзя добавить как нативный виджет iOS. Для виджета используется бесплатное приложение Scriptable. Оно читает экспортированный файл словаря из iCloud Drive.

  1. Установи ScriptableСкачай Scriptable из App Store.
  2. Экспортируй словарьНажми «Скачать файл для виджета» ниже. Сохрани words.json в iCloud Drive → Scriptable → WordHour.
  3. Создай скриптВ Scriptable создай новый Script, назови его Word Hour, открой файл WordHour-Widget.js из комплекта и скопируй его содержимое.
  4. Добавь виджетНа главном экране iPhone удерживай пустое место → «+» → Scriptable → выбери размер виджета → добавь его → в настройках виджета выбери скрипт Word Hour.

Виджет запрашивает обновление примерно раз в час, но фактическое время обновления контролирует iOS и оно может задерживаться. После изменения словаря экспортируй JSON ещё раз и замени старый файл в iCloud Drive.

Скрипт виджета
Код Scriptable входит в комплект приложения (файл WordHour-Widget.js).
