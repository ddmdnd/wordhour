# Word Hour

Персональное приложение для списка английских слов: новое слово каждый час, словарь, прогресс и настоящий виджет iPhone через Scriptable.

## Что внутри
- PWA с русским интерфейсом, устанавливается на iPhone через Safari.
- Импорт CSV, TXT, JSON и XLSX (для XLSX нужен интернет при первом использовании модуля SheetJS).
- Хранение слов и прогресса локально в браузере (IndexedDB).
- Смена слова по часовым интервалам местного времени; слова не повторяются в рамках цикла.
- Отметки «выучено» и «сложное», поиск, фильтры, статистика, история.
- Экспорт резервной копии JSON и отдельного `words.json` для виджета.
- Скрипт Scriptable для iOS.

## Как запустить
PWA должен открываться по HTTPS (например, на GitHub Pages, Netlify или другом статическом хостинге). Открытие `index.html` напрямую из файлового менеджера не даёт полноценную установку PWA.

1. Размести содержимое папки `word-hour-app` на HTTPS-хостинге.
2. Открой адрес сайта в Safari на iPhone.
3. Нажми «Поделиться» → «На экран Домой» → «Добавить».
4. Запусти Word Hour и импортируй CSV/TXT/JSON/XLSX.

## Формат списка
Рекомендуемые заголовки CSV:

`word,translation,uk,phonetic,pos,level,example,example_translation`

Минимально достаточно `word,translation`. Можно скачать образец CSV в окне импорта. TXT: одно слово на строку; если есть перевод, разделяй его дефисом, тире, табуляцией или символом `|`.

## Как добавить настоящий виджет iPhone
1. Установи приложение Scriptable из App Store.
2. В Word Hour открой вкладку «Виджет iPhone» и нажми «Скачать файл для виджета».
3. В приложении «Файлы» сохрани `words.json` в `iCloud Drive/Scriptable/WordHour/`. Если папки `WordHour` нет, создай её.
4. В Scriptable создай скрипт с названием `Word Hour`, вставь код из `WordHour-Widget.js` и сохрани.
5. На главном экране iPhone удерживай пустое место → `+` → Scriptable → выбери размер → добавь виджет.
6. Удерживай добавленный виджет → «Изменить виджет» → Script → `Word Hour`.

После изменения словаря снова экспортируй `words.json` и замени старый файл в iCloud Drive.

## Ограничения iOS
Scriptable просит iOS обновить виджет примерно через час, но iOS сама решает, когда обновлять виджеты. Обновление может задерживаться из-за режима энергосбережения, фоновой активности и других системных ограничений. Это не гарантированно точный таймер.

## Конфиденциальность и данные
Словарь и прогресс хранятся локально в браузере на устройстве. Не очищай данные Safari для этого сайта, если не сделал резервную копию через экспорт JSON. Виджет получает локальный экспортированный файл из iCloud Drive; облачная синхронизация словаря между устройствами не реализована.
